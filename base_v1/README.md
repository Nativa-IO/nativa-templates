# Nativa Base V1

Template base para proyectos Nativa con React + Vite, FastAPI y Docker.

## Runtime

El `docker-compose.yml` de la raiz esta pensado para preview/smoke tests:

- Frontend: `npm run build` durante el build de imagen y `npm run preview` al arrancar.
- Backend: `uvicorn app.main:app --host 0.0.0.0 --port 8000`, sin `--reload`.
- Database: no se levanta Postgres por sesion; `DATABASE_URL` debe apuntar a la DB del proyecto.
- Networking: los servicios usan `expose` y labels de Caddy. No publican puertos al host.

## Variables

La raiz del proyecto debe tener un `.env` con al menos:

```env
DATABASE_URL=postgresql://USER:PASSWORD@HOST:5432/DB_NAME
PROJECT_NAME=Nativa App
API_V1_PREFIX=/api/v1
SECRET_KEY=change-me
ACCESS_TOKEN_EXPIRE_MINUTES=1440
ALGORITHM=HS256
```

Para routing via Caddy/Nativa:

```env
PUBLIC_FRONTEND_HOST=session.workspace.preview.devnativa.com
PUBLIC_API_HOST=api-session.workspace.preview.devnativa.com
CADDY_INGRESS_NETWORK=nativa-ingress
```

## Comandos Locales

Frontend:

```bash
cd frontend
npm ci
npm run dev
npm run build
npm run preview
```

Backend:

```bash
cd backend
pip install -e .
uvicorn app.main:app --reload
```

## Docker

Para levantar el stack de preview/smoke:

```bash
docker compose up --build
```

Para detenerlo:

```bash
docker compose down
```
